⛽ FuelEase – Fuel Management System
FuelEase is a full-stack web application designed to streamline fuel distribution, especially during supply shortages. It includes online reservation, dynamic fuel allocation, emergency vehicle prioritization, inventory tracking, and real-time notifications, making fuel management more efficient and fair.

🚀 Features
✅ Online Fuel Reservation
Book fuel slots in advance through a web-based platform.

🚓 Emergency Vehicle Priority
Automatically recognizes emergency vehicle numbers and prioritizes their reservations.

🔐 User Authentication
Secure login and registration for customers and administrators.

📊 Real-time Inventory Monitoring
View available fuel quantities across fuel types.

🖥️ Web-Based Interface
Responsive, user-friendly UI using TailwindCSS and React.

🧠 Dynamic Fuel Allocation
Allocate fuel based on availability and reservation volume using smart logic.

📩 Smart Notification System
SMS and email updates for reservation confirmations and alerts.

🛠️ Tech Stack
Frontend: React.js, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT
Notifications: Twilio (SMS), Nodemailer (Email)
